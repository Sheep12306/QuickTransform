保留颜色 / 下划线样式
开启：颜色、高亮、下划线会用 HTML 标签保留，例如 <span>、<mark>、<u>。部分 Markdown 编辑器或云端平台不支持 HTML，可能显示为源码或不渲染。 关闭：这些样式会转为纯 Markdown 文本，跨平台兼容性最好，但会丢失颜色、高亮和下划线样式。
图片
文件夹：图片单独保存，Markdown 引用相对路径，源码短、便于编辑。 内嵌：图片转成 Base64 直接写进 Markdown，一个文件即可带走，但源码会很长。 占位符：只保留插入位置提示，图片后续手动插入，适合检查正文。
